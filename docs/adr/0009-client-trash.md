# Clients go through the Trash before hard delete

Staff and Owner can remove a Client to the Trash, restore it, or delete it from the Trash. Restore keeps Visibility: a public Client returns to the Roster. The Trash is only for Clients. Users, Categories, and ContactRequests are not in it. ContactRequest “archived” stays the inbox.

**Considered:** Visibility-only hide (no Trash). Soft delete without restore. Owner-only hard delete. One trash for every destroyable row.
